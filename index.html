01我们如何处理数据

扩展在你主动打开阅读模式后，读取当前网页中可访问的内容，在浏览器内提取正文并显示阅读界面。提取出的标题、文字、图片地址和当前页面地址用于阅读、打开原网页及关联本页记录。阅读过程中会在内存中处理网页内容；本地处理也属于处理用户数据。网页文字以及你输入的批注可能包含个人或敏感信息，请根据内容决定是否保存。

当前扩展没有注册账号、云端同步、开发者接收正文的上传接口或扩展内分析遥测，不将正文、批注、阅读库和设置发送给开发者，不出售这些数据，也不用于广告或广告画像。它不主动遍历所有浏览历史，不通过专门接口读取密码、Cookie 或账号凭据；这些边界不意味着你正在阅读的网页正文不含个人信息。

在线阅读界面可能继续加载原网页图片等远程资源；请求会受浏览器和原网站的网络、Cookie 及隐私规则影响，资源提供方可能收到 IP 地址等网络信息。原网站页面与脚本也可能继续运行。点击“查看原网页”等链接会访问相应网站。扩展不是网络隔离、广告拦截或反跟踪工具，不能承诺阅读时完全不联网。离线文字快照则不下载或加载原网站的图片、脚本等第三方资源。

02本机保存什么

数据位于当前 Chrome 配置文件的扩展本地存储中，不是扩展的云存储。我们没有为这些数据增加应用级加密。

数据保存时机与内容保留与移除
阅读设置保存主题、字号、行高、行宽等偏好；阅读界面调整会保存，本地设置页也可保存可用“彻底清除全部项目用户数据”移除；普通关闭阅读不清除
高亮与批注你主动创建或编辑时保存选中文字、附近短上下文、位置、内容校验信息、纯文本批注、记录标识和时间保留版本日志、冲突版本、旧版副本及删除标记，不自动定期清理；删除可见高亮不等于删除这些历史
本地阅读库仅在你主动点击“保存到稍后读”后保存当前提取结果的标题、文字结构、状态、站点/作者信息（如有）和时间等同页保留当前与上一版；再次成功更新时更早版本被替换；最多 20 条、合计 5MiB，单份快照最多 200KiB，不自动淘汰其他条目
恢复临时副本整体导入期间，保存导入前的数据以便失败时撤回正常完成并核对后移除；中断时可能留待下次核实处理，不能视为已完成清除
会话控制信息用随机代次、版本及操作状态协调清除/恢复，阻止旧窗口回写清除全部项目用户数据后仍保留最小控制键 data-control:state:v1，不含正文或批注

页面记录用去掉地址片段后的 URL 计算哈希进行关联，查询参数也参与计算；保存结构不以独立来源 URL 字段保留完整原网页地址。这不是不可逆匿名化的承诺。批注是你输入的文字；网页标题、正文或选中文字本身仍可含姓名、地址、令牌等敏感内容。阅读库对可识别的网页地址文字做有限的查询参数/片段清理，不是通用个人信息脱敏工具。

离线阅读库只保留文字及部分结构，图片为提示，外链保留文字而不可点击，不保留视频、iframe 或背景图资源。快照可能不完整；保存不会突破网站登录、付费或访问控制。

03为什么需要这些权限

  • activeTab：在你点击扩展操作后，临时访问当前标签页以读取并整理内容，不授予长期访问所有网站的权限。
  • scripting：在获准的当前页面运行随扩展打包的阅读脚本，显示和关闭阅读界面。
  • storage：在当前浏览器保存设置、批注、主动保存的阅读库和数据操作状态，供重开和本地管理使用。

当前没有新增所有网站访问、浏览历史、Cookie、账号、下载管理或无限存储权限。备份通过浏览器的普通文件下载流程交给你保存，不使用下载管理权限。

04备份与恢复

你可在扩展设置的“数据管理”中主动导出 JSON 备份。文件包含设置、全部批注历史/删除标记/旧副本，以及阅读库当前和上一版，是明文文件。SHA-256 校验用于发现文件变化或损坏，不是加密、签名或来源认证。请确认文件实际保存，并选择可信的存放位置；文件若被其他人或软件取得，其中的正文和批注可能被读取。

导出不自动上传。如果你选择系统云盘目录、邮件或其他分享渠道，文件会按相应服务的规则处理，扩展不控制这些服务，也不会替你删除副本。

导入由你主动选择本地文件，校验和预览后再次确认。恢复会整体替换设置、批注和阅读库，并移除备份中没有的项目数据，不进行合并。文件最大 12MiB、用户数据最多 11MiB/50000 键，阅读库仍有原容量限制；临时副本需要额外空间。空间不足或数据异常会拒绝操作，不自动清空腾空间。失败或中断需按提示核实、撤回或明确放弃恢复并清除，不会把失败称作成功。

05查看、更改和彻底清除

你可在阅读界面管理本页高亮/批注，在本地阅读库查看或删除快照，在数据管理中盘点、导出及选择清除范围。单独“删除高亮”只删除当前可见记录，历史仍可能存在；如需移除其历史，选择“全部批注（含历史、墓碑、旧副本）”。删除阅读库条目会连同该条目的上一版移除。

数据管理的彻底清除需要明确确认，可以选择全部批注、全部阅读库或全部项目用户数据。选择全部项目用户数据时，会移除阅读设置、批注各版本、阅读库两版和恢复临时副本（如有），保留上述不含正文/批注的最小会话控制信息。其他未识别本地键会在盘点中显示，不承诺替你清除不属于这些范围的数据。

清除只移除当前配置文件中的相应浏览器存储键，不是磁盘取证级安全擦除。它不会删除已经导出的备份、原网站数据、浏览器缓存或其他打开窗口的内存。旧阅读/设置窗口会停止写入，请关闭重开；需要清除屏幕上或内存中的旧内容时，也应关闭相关窗口。重开并再次使用功能会产生新的设置或记录。开发者没有云端副本，不能替你找回未备份或已覆盖的数据。

06支持和政策变更

支持渠道：ketchup121@qq.com。当前扩展不自动发送诊断日志。如果你主动发邮件反馈，接收方会处理你提供的邮箱地址、问题描述及附件；请避免提交正文、账号信息或完整备份。支持邮件仅用于处理反馈与必要跟进。问题结束后，运营者将在90天内删除相关支持邮件；你可以向同一邮箱申请提前删除，依法必须保留的除外。该规则适用于运营者管理的邮件，邮件服务商的处理及删除规则由其服务条款和隐私政策规定。

公开政策变更将由运营者在本页面说明。未来若增加账号、同步或其他处理方式，必须先另行确认实现和披露。
